# Astribot T1 双臂一笔画 Agent 规范 v1

## 目标与模型
仅适用 Astribot T1，官方 aos 提交 cab872dc00081d2c5b096c7a19e563050eb7a2ff。固定底盘、共享可动躯干、双臂同步，不包含人体。不得复用 S1 的可达区/执行通过结论。

## 画布与坐标（不可自行缩放、裁切或镜像）
- PNG：616×560，白底或透明，RGB/RGBA；SVG：width="616" height="560" viewBox="0 0 616 560"。
- 连续像素边界坐标，像素中心为整数+0.5。单位米：x=-0.77+0.0025*u，y=-0.42，z=1.89-0.0025*v。
- 机器人左臂对应画面右半边 x≥0，机器人右臂对应画面左半边 x<0。不是观看者的左右。
- 使用随附 t1-canvas/mask-left.png 与 mask-right.png；非零像素是各臂允许设计区域。轨迹中心线必须位于其对应 mask 内，最好离边界至少8像素。不得把边界框等同于可达区。
- Mask 来源：11个躯干姿态、2cm离散采样、位置IK与全模型已列出碰撞对筛查；填充单元不是每个像素的验证。两臂各自可达的并集不代表任意两点能同时执行。

## 必须交付
1. preview.png：上述尺寸，左臂蓝 #00649b、右臂橙 #914100，2px中心线；不把装饰/文字转换成轨迹。
2. paths.svg：每臂恰好一个连续 path；每个 path 仅一个 M，无断笔、无填充、无图像嵌入。允许 L/C/Q，不用不确定的字体轮廓。
3. paths.json：schema="astribot-t1-path-v1"，width=616,height=560，coordinate_system="continuous_pixel_edges"，arms.left/right 各包含 points_uv=[[u,v],...] 与 progress=[0,...,1]。相邻点不重复，每段≤1像素；progress严格递增，起止0和1，表示共同归一化进度，不是已批准的物理时间。
4. validation.json：尺寸、有限数值、连通性、mask包含性、段长检查，标记 execution_status="UNVALIDATED"。不能仅凭图片声称可执行。

## 轨迹要求
每臂一条不中断的轨迹；避免尖角、急回折、密集自交。双臂共用一条时间轴；不得分别选互不兼容的躯干姿态。绘图前进场、绘图后退场同样要规划和验证。

## 执行门禁
由规划器重新求解共同躯干+两臂，验证关节位置/速度/加速度、可达误差、奇异性与所有阶段碰撞；随后验证实际执行状态，而非只验期望状态。当前演示采用指定共享躯干轨迹+双臂补偿，不是通用全身优化器。未通过的设计应缩小/移位/简化再验证，不能修改mask掩盖失败。

当前碰撞模型有3947个显式检查对，采用官方碰撞网格的凸包。排除了结构相邻/刚性部件；T1复合肘3/5、复合腕及前臂5对夹爪基座官方网格有声明的关节接口排除，手指/接触垫/画笔仍检查。局部折叠、自碰撞精确网格、连续时间和真实机器人安全尚未认证。采样通过不等于硬件安全许可。
